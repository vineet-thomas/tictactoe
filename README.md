# Tic Tac Toe

**A simple browser-based Tic Tac Toe game built using HTML, CSS, and JavaScript.**

## About

This project is a small demo application to experiment with building interactive games on the web using fundamental front-end technologies.  
It features a basic implementation of Tic Tac Toe, allowing two players to compete on a 3x3 grid.

## Features

- Interactive 3x3 Tic Tac Toe board
- Two player mode (local, on the same device)
- Highlights the winner and detects draw conditions
- Responsive design for desktop and mobile screens
- Clean, readable codebase with separate files for HTML, CSS, and JavaScript

## Technologies Used

- **HTML** (19.2%)
- **CSS** (32.8%)
- **JavaScript** (48.0%)

## Getting Started

1. **Clone the repository**:
    ```bash
    git clone https://github.com/vineet-thomas/tictactoe.git
    ```
2. **Open `index.html` in your browser**.

No additional dependencies required.  
Just use any modern web browser.

## File Structure

- `index.html` — The main HTML file containing the game markup
- `styles.css` — Basic styles for board layout and responsiveness
- `script.js` — JavaScript logic that powers the game
